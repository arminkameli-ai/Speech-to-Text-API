# 🇬🇧 English

## 📖 About the Project

This project is a simple Speech-to-Text application developed in Python using the **SpeechRecognition** library and **Google Speech Recognition API**.

The application records audio from the microphone and converts spoken **Persian (Farsi)** into text.

---

## ✨ Features

- 🎤 Real-time microphone recording
- 🇮🇷 Persian (Farsi) speech recognition
- ☁️ Google Speech Recognition API
- ⚡ Lightweight and easy to use
- 🐍 Built with Python

---

## 🛠 Technologies Used

- Python
- SpeechRecognition
- PyAudio
- Google Speech Recognition API

## ▶️ Installation

Install the required libraries:

```bash
pip install -r requirements.txt
```

---

## ▶️ Run

```bash
python speech_to_text.py
```

---

## 📌 Notes

- Internet connection is required.
- The application uses Google's online Speech Recognition service.
- The current version recognizes **Persian (fa-IR)** speech only.
